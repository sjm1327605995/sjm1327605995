#### 🎨 [Tenon](https://github.com/sjm1327605995/tenon)
> A fine-grained reactive UI framework for Go, powered by Ebiten and Yoga.

```
┌─────────────────────────────────────┐
│  Widget (immutable description)     │
│  Render() → Element tree            │
├─────────────────────────────────────┤
│  Element (lifecycle manager)        │
│  Connects Widget ↔ RenderObject     │
├─────────────────────────────────────┤
│  RenderObject (layout + paint)      │
│  Yoga flexbox + Ebiten GPU          │
├─────────────────────────────────────┤
│  State (fine-grained signal)        │
│  Set() → direct element update      │
└─────────────────────────────────────┘
```
